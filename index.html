NetTango Tutorial

Your students build the model to learn the science

NetTango turns NetLogo models into blocks your students snap together. They set the rules, press GO, and watch the results unfold. No coding experience needed. Runs in the browser.

Model real world phenomena from simple blocks

Each model provides blocks for a single phenomenon, such as ant foraging, gas particles, or spaceship flight. Students work only with the blocks that phenomenon requires, without first learning a programming language.

In Antomology Introduction, students start with two blocks: one that moves the ants and one that makes them wander. Each later model in the sequence adds a few blocks, such as picking up food or dropping a chemical trail. Open Antomology Introduction

Antomology - Pheromones

Explore how ants use pheromones to find their way. Your students build the rule for laying a chemical trail and observe whether the ants mark a path back to the nest.

Try this one!: Antomology - Pheromones

Spaceship Programming

Explore how a spaceship moves when its engines fire. Your students schedule each engine with blocks and observe that the ship keeps moving until an opposing engine fires.

Try this one!: Spaceship Programming

Two Particles in a Box

Explore how gas particles interact in a closed box. Your students build the collision rule and observe how collisions change the motion of the particles.

Try this one!: Two Particles in a Box
