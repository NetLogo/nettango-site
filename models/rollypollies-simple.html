Tips for class

  • The Info tab is empty and behave like rollypollies starts empty. After setup every rollypolly sits at the center, between the chambers, so both monitors read 0 until they move.
  • Pick dry or moist in condition-in-chamber1 and condition-in-chamber2, type the preferred condition (for example moist) into preferred-conditions, and press update conditions.
  • A good first build: under if on a preferred patch put chance with move, and under if not on a preferred patch put move alone. Ask which chamber plot will rise before pressing go.
  • Use this after Rollypollies, where students build the chambers themselves. Here the chambers are ready, so class time goes to the behavior rules.
